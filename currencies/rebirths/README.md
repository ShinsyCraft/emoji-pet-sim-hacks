To use this script you paste it into the console.
Before running the script, pause the scripts in the `Sources` tab.
<img width="350" height="250" alt="image" src="https://github.com/user-attachments/assets/619b8e3b-07de-46fd-a07d-c5453836174d" /><br>
Then run the script, then refresh the page.
You should have 10,000 rebirths now.<br>
To modify the amount, change this line:<br>
`saveData.rebirths = 10000;`<br>
To your desired amount.
